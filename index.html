About this data

Official City of Spokane Police Department public records. This is Spokane-area public data as of its as-of date, not a real-time feed. Locations are shown at neighborhood level only. Street addresses are not published on CrimeStat.

Time presets are measured from the data as-of date, not from today.

Crime layers

    Types marked “area only” are neighborhood totals — never a pin or address. Calls are 911/CAD events, not confirmed crimes, and start off.

    Install CrimeStat

    You can install the free CrimeStat website on your iPhone or Android home screen. It works like an app: same map, same layers, no App Store or Google Play download.

    On iPhone in Safari, tap the Share button, then Add to Home Screen. On Android in Chrome, use the Install app button when it appears.

    A separate iPhone and Android app, built with Expo, is still coming later. It is not in the stores yet.
