CrimeStat

Request block-level crime records

Last updated November 25, 2026.

Some cities only publish yearly totals, or no reusable incident feed, so CrimeStat cannot place pins on a block. You can ask the local police or sheriff for a public extract. CrimeStat does not file, sign, or submit records requests for you.

What to ask for

Request a machine-readable file (CSV or JSON) of reported crime incidents, under the Washington Public Records Act, chapter 42.56 RCW, with:

  • Incident or report date and time
  • Offense or NIBRS code and offense type
  • Location at the 100-block, or official coordinates already blurred to the 100-block
  • A report number only if it does not identify a person
  • City, beat, or reporting district, if those fields exist

Ask the agency to omit names, precise home addresses, dates of birth, and other personal identifiers, and to redact anything it treats as exempt. Then ask whether the same non-identifying fields can be published as a regular open data feed.

How to send it

  1. Identify the agency that actually polices the city (city police, a contracted sheriff, or both) and use that agency’s official public records portal or email.
  2. Paste a short request that cites RCW 42.56 and lists the fields above. A template is at the bottom of this page.
  3. Keep the date you sent it and any tracking number. If there is no acknowledgment in about five business days, send a brief status follow-up.
  4. If the agency denies location data, ask whether a 100-block version can be released, and which exemption was applied.

This page is a how-to, not legal advice. Full steps are also in the project’s public records playbook.

Short request template

Subject: Public records request — block-level crime incidents (RCW 42.56)

This is a request for public records under the Washington Public Records Act, chapter 42.56 RCW.

Please provide a machine-readable copy (CSV or JSON) of reported crime incidents for [agency / city], for [date range, or “the most recent 12 months, and ongoing if available”], with these fields only:

- incident or report date and time
- offense or NIBRS code and offense type
- location at the 100-block, or official coordinates already blurred to the 100-block
- incident or report number, if it does not identify a person
- city, beat, or reporting district, if available

Please omit names, precise residential addresses, and other personal identifiers. Please also omit or redact any fields you determine are exempt, and release the remaining non-exempt fields.

If a one-time extract is all that is available now, I also request that [agency] consider publishing the same non-identifying fields as a regularly updated open data feed, with stated reuse terms.

If this request needs clarification or a time/cost estimate, please let me know.

Replace the bracketed placeholders before you send this. Do not include anyone else’s name, phone number, or home address unless the agency requires a requester mailing address, in which case use your own.
